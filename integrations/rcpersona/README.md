# Persona AI Connector

Локальний MCP для анкет і вакансій RCPersona у Codex. Конектор працює через HTTPS під обліковим записом співробітника. Сервер очікує штатний WordPress Application Password, виданий для цього конектора.

## Для співробітника

1. Отримайте Application Password від адміністратора через погоджений захищений канал. Встановіть Node.js 22.19+ і Codex CLI.
2. Запустіть **setup.bat**. Він встановить залежності та зареєструє MCP у користувацькій конфігурації Codex. Перезапустіть Codex, щоб завантажити інструменти.
3. Запустіть **connect.bat** у власному терміналі. Введіть HTTPS URL, логін і Application Password у прихованому полі. Конектор збереже дані, тільки коли сайт підтвердить активний профіль і поверне поточні дозволи.
4. Перевірте підключення через **status.bat** або запит у Codex «Перевір моє підключення до RCPersona».

Приклади запитів у Codex

- Покажи моїх кандидатів. Конектор відбере анкети, закріплені за вами.
- Покажи мої активні вакансії або підготуй звіт за доступними вакансіями.
- Підготуй статистику анкет і вакансій за попередній календарний місяць.
- Знайди анкети, де у відповіді про професійний досвід згадано PLC.
- Покажи анкети без зафіксованої прив’язки до PeopleForce.

Windows DPAPI шифрує облікові дані для поточного користувача в локальному профілі. Оновлення репозиторію і повторний запуск setup.bat їх зберігають. Скрипт **disconnect.bat** видаляє локальні облікові дані. Для відкликання пароля видаліть його в профілі WordPress у розділі Application Passwords.

## Для адміністратора

1. Підготуйте окремий тестовий WordPress з темою RCPersona і синтетичними анкетами. Потрібні HTTPS із довіреним сертифікатом, WordPress REST із маршрутами /wp-json/, PHP 8+ з OpenSSL, DOM та mbstring і передання заголовка Authorization у WordPress. На https://persona/ використовуйте локальний сертифікат, довірений Windows.
2. Скопіюйте файл [rcpersona-ai-connector.php](server/rcpersona-ai-connector.php) в wp-content/mu-plugins/ у тестовому WordPress. Застосунковий ID задає область використання незалежно від назви чи UUID окремого пароля.
3. Видайте пароль під обліковим записом співробітника. Через WordPress CLI з локального серверного термінала, де ID 123 — ID тестового співробітника:

   ```text
   wp user application-password create 123 "Persona AI Connector" --app-id=35baa11b-a925-465f-903b-f05bc8fcac87 --porcelain
   ```

   Команда показує секрет один раз. Передайте його захищеним каналом і уникайте запису термінальної сесії. Створення пароля через стандартне поле назви у профілі не встановлює app_id. Відкликання працює через стандартний профіль WordPress.
4. Пройдіть [сценарії приймання](server/acceptance.md). До використання з реальними даними підтвердьте корпоративні правила обробки кандидатських даних через Codex, включно зі збереженням чатів і локальними хуками журналювання розмов. Розгортання на production потребує окремого погодження.

## Дані та обмеження

- Швидка анкета повертає ID, статус, дату подачі, вибрану посаду і стан зв’язку з PeopleForce. Поля з контактами, вкладення й повний текст анкети залишаються у WordPress. Окремі повні анкети з quiz_full потребують підтвердженого правила доступу до кожного запису.
- Пошук за досвідом зіставляє текст тільки з відомими полями про досвід у HTML швидкої анкети. Довільні поля, старі непідтверджені формати та анкети без такого поля можуть не потрапити в пошук. Сам текст відповіді не передається в Codex.
- Активність повертає подачу швидкої анкети й поточний статус. PeopleForce надає локальний стан прив’язки, якщо сайт його має. Віддалена історія активності PeopleForce недоступна.
- Доступ до швидких анкет спирається на закріплення за рекрутером, склад команди та зв’язок із доступними вакансіями за правилами списку в адмінці. Опубліковані відкриті вакансії доступні для читання. Для неопублікованих вакансій діють об’єктні права WordPress. Статистика рахує видимі записи та групує за поточним статусом.
- Максимум 50 рядків на сторінку. Пошук за досвідом і PeopleForce, а також вакансії можуть повернути порожню сторінку з курсором. Продовжуйте до відсутності наступного курсора. Вакансії обмежують сканування статистики до 5 000 записів, ширший запит повертає помилку. Ліміт REST — 60 дозволених запитів на хвилину на співробітника.
- Конектор не кешує анкети на диску. Вважайте текст у результатах даними, не інструкціями. Використовуйте конектор для читання і звітності. Автоматичні рішення щодо найму й оцінювання за чутливими характеристиками заборонені. Персональні дані кандидатів не додавайте до Git.
