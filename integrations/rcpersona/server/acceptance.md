# Приймання на тестовому RCPersona

Використовуйте синтетичні анкети, вакансії і тестових співробітників. Спочатку порівняйте видимість із UI RCPersona, потім повторіть дії через REST і Codex.

| Дані або дія | Очікуваний результат |
|---|---|
| Працівник уже увійшов у WordPress | Відразу бачить форму підтвердження |
| Працівник без браузерної сесії | WordPress показує штатний вхід і повертає до підтвердження |
| Відхилення, прострочення, неправильний verifier, повторний обмін | Сесія не видає пароль або відхиляє повторний обмін |
| Активний працівник і пароль з app_id конектора | /me повертає ID, active і поточні дозволи |
| Вимкнення профілю після підключення | Наступний запит відхилено |
| Помилковий, відкликаний або звичайний Application Password | Нові маршрути відхиляють підключення |
| Рекрутер, тімлід, адміністратор | Видимість перевірена для власного, командного, закріпленого за вакансією, нерозподіленого, видаленого й стороннього запису |
| Сторонній ID в деталях і активності | Той самий 404, що й для відсутнього запису |
| Фільтр із терміном, який має лише стороння анкета | Немає збігу в списку та приросту в статистиці |
| Зміна складу команди або призначення | Наступні пошук, деталі й статистика враховують зміну |
| Публічна, захищена паролем, приватна і чернетка вакансії | Деталі, список і статистика застосовують об’єктні права однаково |
| POST, PUT, DELETE, method override, /wp/v2/users/me, REST batch, XML-RPC або старий namespace із паролем конектора | Відхилено |
| Серія понад 60 запитів за хвилину | Після ліміту — HTTP 429 |
| Позначки PeopleForce і працівник із правильними правами | Пошук розрізняє записи зі збереженою прив’язкою і без неї |
| Оновлення Git та повторний запуск setup.bat | status.bat підтверджує існуюче підключення |
| disconnect.bat і повторний status.bat | Локальні дані видалено, потрібне нове підключення |
| Старий сервер, компонент 1.1, несумісна версія API | Новий MCP запитує можливості і повертає інструкцію про оновлення для несумісної версії |
| Пошук кандидата за іменем, email та телефоном | У межах прав повертаються відповідні записи. Контакти в результаті з’являються лише з `include_contacts=true` |
| Повна анкета з професійною відповіддю та документом | До результату потрапляє дозволена відповідь. Документи, номери та вкладення відсутні |
| Дві повні анкети для однієї короткої заявки, ще одна автономна | Є окремі ID повних анкет. У статистиці коротких заявок кандидат врахований один раз. Автономна анкета має порожній `candidate_id` |
| Фільтри `full`, `quick_only`, `none` і видалена анкета | Вибірка відповідає фактичній наявності активної повної анкети. Видалена анкета не враховується |
| Чернетки зі статусом `draft` та `failed` | Доступні адміністратору. У результаті відсутні контакти, токени, чернеткові відповіді та припущення щодо кандидата |
| Персональний, командний та адміністративний звіт за одним періодом | Обсяги збігаються з призначеннями. Після зміни ролі повторний запит застосовує нові права |
| Рекрутер запитує чужого рекрутера, командну статистику, довідник рекрутерів або сторонній ID | Запит відхиляється. Загальна кількість співробітників не розкривається |
| Точний пошук робочого контакту, однофамільці, приватний домен, 13 звернень за годину | Доступний службовий контакт, для кількох збігів потрібне уточнення, приватний email приховано, після ліміту HTTP 429 |
| Розподіл за вакансіями та деталізація | Загальний підсумок не дублює заявку, прив’язану до кількох вакансій. Деталізація використовує той самий період і scope |
| Вибірка за тижнем із переходом між місяцями, групування джерело + рекрутер | Тиждень починається в понеділок. Сума неперетинних груп дорівнює повній дозволеній вибірці |
| Сторінки за зростанням і спаданням ID, зміна фільтрів | Відсутні дублікати для сталої вибірки. При зміні фільтра починайте з першої сторінки |
| Журнали WordPress, вебсервера, проксі й APM | Аудит містить час, ID працівника, операцію та результат. Секретів, пошукових контактів, відповідей і тіл REST-відповідей немає |

Клієнтські перевірки виконуються через npm test. У репозиторії теми виконайте php tests/persona-ai-connector-test.php з PHP DOM, mbstring, OpenSSL і SQLite PDO.
